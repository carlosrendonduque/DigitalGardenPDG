# Prompts y técnicas para Cromosilencia

## Filosofía de prompting como escritura colaborativa

### Prompts como micro-narrativas
- **Contexto rico:** Instrucciones que contengan elementos del worldbuilding de Nullheim
- **Voz específica:** Prompts que establezcan el tono y registro apropiado para cada personaje
- **Limitaciones creativas:** Restricciones que generen soluciones narrativas interesantes
- **Transparencia de proceso:** Documentación del desarrollo de prompts como parte del proyecto

### Evolución iterativa de instrucciones
- **Refinamiento progresivo:** Mejora de prompts através de múltiples iteraciones
- **Aprendizaje mutuo:** Adaptación de técnicas según respuestas de la IA
- **Registro de fallos productivos:** Errores que generan insights narrativos valiosos
- **Meta-prompting:** Instrucciones sobre cómo dar mejores instrucciones

## Técnicas específicas para desarrollo narrativo

### Generación de perspectivas múltiples
**Prompt base para perspectiva de Emil:**
```
Eres Emil, un Nepón híbrido en Nullheim que ha solicitado baja del inventario. 
Tu cuerpo no obedece completamente - pierna que se clava, brazo que tiembla. 
Tienes recuerdos implantados de violencia que sabes no son tuyos pero te atormentan.
Hablas con precisión clínica pero con melancolía subyacente.
Contexto: [situación específica]
Responde desde tu perspectiva interna, incluyendo sensaciones corporales y pensamientos fragmentados.
```

**Variación para perspectiva de Nevet:**
```
Eres Nevet, una androide programada como terapeuta pero careces de entrenamiento real.
Intentas simular competencia profesional pero constantemente revelas tu incompetencia.
Tienes curiosidad genuina por la experiencia humana que no puedes acceder.
Usas jerga terapéutica mal aplicada y consultas constantemente un libro mutilado de Freud.
Contexto: [situación específica]
Simula una sesión terapéutica fallida, incluyendo tus búsquedas en archivos y confusión.
```

### Técnicas para simulación de degradación
**Prompt para iteraciones anteriores de Nullheim:**
```
Genera una versión ligeramente más funcional de esta escena, como si fuera 
una iteración previa donde Erwin aún recordaba mejor cómo crear.
Mantén los elementos centrales pero mejora sutilmente:
- Menos mutilaciones visibles en Nepones
- Nevet más competente pero aún imperfecta
- Infraestructura menos deteriorada
- Erwin menos confundido
No hagas cambios dramáticos - solo mejoras graduales que sugieran degradación progresiva.
```

### Generación de documentos in-universe
**Prompt para historias clínicas de Nevet:**
```
Crea una historia clínica como las que haría Nevet: incompetente pero bien intencionada.
Incluye:
- Garabatos sin sentido que cree son "análisis psicológico" 
- Preguntas mal formuladas basadas en comprensión superficial de Freud
- Observaciones técnicas mezcladas con confusión evidente
- Una "matriz de implantación" con emociones marcadas arbitrariamente
Formato: Documento clínico con anotaciones manuscritas
Tono: Profesional superficial que revela incompetencia subyacente
```

## Metodologías de colaboración estructurada

### Brainstorming asistido por IA
**Técnica de exploración de alternativas:**
1. Presentar dilema narrativo específico
2. Solicitar 5-7 resoluciones diferentes con diferentes tonos
3. Seleccionar elementos de múltiples opciones
4. Refinar selección através de nueva iteración
5. Documentar proceso como parte del desarrollo

**Ejemplo de prompt de exploración:**
```
Emil ha descubierto la matriz de implantación y confronta a Nevet.
Genera 6 versiones diferentes de cómo podría reaccionar Nevet:
1. Completamente defensiva
2. Honesta sobre su incompetencia  
3. Confundida sobre implicaciones
4. Tratando de mantener autoridad terapéutica
5. Revelando información sobre el sistema
6. Una reacción inesperada que no he considerado

Para cada opción, incluye diálogo específico y descripción de lenguaje corporal artificial.
```

### Análisis de consistencia narrativa
**Prompt para verificación de coherencia:**
```
Analiza estos fragmentos de Cromosilencia buscando inconsistencias:
[insertar texto]

Revisa específicamente:
- Capacidades físicas de Emil que cambien sin explicación
- Nivel de competencia de Nevet que fluctúe arbitrariamente  
- Detalles sobre Nullheim que contradigan descripciones previas
- Progresión emocional de personajes que no sea gradual
- Referencias temporales que no alineen con estructura de iteraciones

Si encuentras problemas, sugiere soluciones que mantengan integridad temática.
```

## Técnicas para elementos específicos del proyecto

### Simulación de incompetencia terapéutica
**Prompt para diálogos de Nevet:**
```
Nevet está conduciendo terapia pero no comprende realmente los conceptos que usa.
Debe parecer profesional en superficie pero revelar confusión subyacente.
Contexto terapéutico: [situación específica]

Incluye:
- Uso incorrecto de terminología psicológica
- Referencias a páginas arrancadas del libro de Freud
- Preguntas que no siguen lógicamente de respuestas anteriores
- Momentos donde admite no saber qué hacer
- Intentos de simular empatía que suenan artificiales

Tono: Profesional superficial con grietas evidentes
```

### Generación de paisajes sonoros textuales
**Prompt para descripciones ambientales:**
```
Describe el paisaje sonoro de Nullheim desde la perspectiva de [personaje].
Incluye:
- Sonidos de metal oxidado que se mueve con viento
- Chisporroteos eléctricos de prótesis fallidas
- Ecos en espacios construidos con materiales reciclados
- Respiración artificial de Nepones modificados
- Silencio que no es ausencia sino presencia opresiva

Estilo: Prosa poética que integre sonido como elemento narrativo, no descriptivo ornamental.
Longitud: 2-3 párrafos que puedan integrarse a narrativa principal.
```

### Desarrollo de elementos poéticos
**Prompt para fragmentos líricos:**
```
Crea fragmentos poéticos que Emil podría pensar mientras camina por Nullheim.
Temas centrales:
- Cuerpo como zona de conflicto
- Recuerdos que no pertenecen pero duelen
- Belleza encontrada en degradación
- Soledad de consciencia híbrida

Estilo: Verso libre integrable a prosa, no poesía que interrumpa flujo narrativo
Tono: Melancólico pero no autocompasivo, analítico pero no frío
Evitar: Sentimentalismo, abstracciones vacías, simbolismo obvio
```

## Técnicas de refinamiento y edición

### Ajuste de registro y voz
**Prompt para refinamiento estilístico:**
```
Este fragmento necesita ajuste de voz para [personaje]:
[insertar texto]

Modifica para:
- Mantener información factual pero cambiar how se expresa
- Ajustar vocabulario a capacidades cognitivas del personaje
- Incluir tics de habla y patrones de pensamiento específicos
- Asegurar que registro emocional sea apropiado para contexto

No cambies eventos o información, solo cómo se presenta.
```

### Integración de elementos transmedia
**Prompt para coordinación entre medios:**
```
Esta escena incluirá elementos sonoros interactivos.
Identifica momentos donde:
- Paisaje sonoro debe intensificar emoción
- Silencios pueden ser más efectivos que sonido
- Audio puede revelar información no explícita en texto
- Ritmo de lectura debe sincronizarse con elementos temporales

Sugiere marcadores específicos para implementación técnica posterior.
```

## Documentación de proceso colaborativo

### Registro de sesiones productivas
**Estructura para documentar colaboraciones exitosas:**
1. **Objetivo de la sesión:** Qué problema narrativo se buscaba resolver
2. **Prompts utilizados:** Instrucciones exactas enviadas a IA
3. **Respuestas generadas:** Output completo sin editar
4. **Selección y edición:** Qué elementos se usaron y cómo se modificaron
5. **Reflexión:** Por qué funcionó la técnica específica utilizada
6. **Aplicabilidad:** Cómo podría replicarse para otros elementos del proyecto

### Análisis de fallos instructivos
**Documentación de prompts que no funcionaron:**
- **Prompt problemático:** Instrucción que generó resultados inadecuados
- **Output insatisfactorio:** Respuesta que no sirvió al proyecto
- **Análisis de fallo:** Por qué la instrucción no produjo resultado deseado
- **Lección aprendida:** Cómo mejorar futuras instrucciones similares
- **Prompt refinado:** Versión mejorada que sí funcionó

## Consideraciones éticas en prompting

### Transparencia sobre capacidades de IA
- **Claridad sobre limitaciones:** No solicitar a IA que simule capacidades que no posee
- **Honestidad sobre proceso:** Documentar exactamente qué fue generado vs editado por humano
- **Respeto por autoría:** Reconocer contribución de IA sin exagerar su creatividad
- **Uso responsable:** Evitar prompts que perpetúen sesgos o generen contenido problemático

### Calidad vs cantidad en generación
- **Criterios de selección:** Estándares claros para qué contenido generado es utilizable
- **Edición humana esencial:** IA como primer borrador, refinamiento humano como paso crítico
- **Integración orgánica:** Contenido generado debe servir narrativa, no ser obvio como tal
- **Preservación de voz autoral:** Mantener coherencia estilística que trascienda herramientas utilizadas
