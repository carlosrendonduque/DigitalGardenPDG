# Prototipos e interfaces - Cromosilencia

## Concepto general de interfaz

### Filosofía de diseño
- **Degradación visual progresiva** que refleje el deterioro del sistema de Nullheim
- **Interfaces que fallan** - botones que no responden, texto que se corrompe, navegación imperfecta
- **Estética de materiales reciclados** - elementos UI que parezcan soldados de fragmentos dispares
- **Respuesta corporal** - la interfaz reacciona al estado emocional del contenido

### Principios de interacción
- **Fricción calculada** - no todo debe ser fluido, algunas acciones requieren esfuerzo deliberado
- **Transparencia de proceso** - mostrar cómo funciona el sistema, no ocultarlo
- **Participación, no consumo** - el lector debe contribuir activamente a la experiencia
- **Temporalidad no lineal** - permitir navegación hacia atrás, adelante, y lateral

## Prototipos específicos

### 1. Interfaz de conexión neural (Emil-Nevet)
**Concepto:** Simular la experiencia de conexión cerebro-máquina del clímax narrativo

**Elementos técnicos:**
- **Sincronización biométrica** - usar cámara para detectar ritmo cardíaco del lector
- **Progresión temporal** - la conexión se establece gradualmente, no instantáneamente
- **Feedback háptico** - vibraciones sutiles si está disponible en el dispositivo
- **Distorsión audiovisual** - glitches controlados que intensifican la inmersión

**Implementación:**
- Pantalla dividida Emil/Nevet que se fusiona progresivamente
- Audio que cambia de estéreo a mono mientras se "conectan"
- Texto que se vuelve compartido - mismo contenido desde dos perspectivas
- Momento final donde el lector debe "autorizar" la liberación

### 2. Consultorio de Nevet
**Concepto:** Experiencia interactiva que simula sesión terapéutica con IA incompetente

**Elementos de interfaz:**
- **Chat simulado** donde Nevet hace preguntas siguiendo protocolos mal entendidos
- **Historial clínico** que el lector puede explorar y modificar
- **Libro de Freud mutilado** - páginas que se pueden "hojear" con contenido fragmentado
- **Garabatos interactivos** - el lector puede dibujar mientras Nevet "analiza"

**Mecánicas específicas:**
- Nevet comete errores obvios que el lector puede señalar
- Respuestas que revelan gradualmente su naturaleza artificial
- Lentes que se puede "limpiar" para cambiar la perspectiva visual
- Acceso a cajones con documentos secretos (matriz de implantación)

### 3. Torre de Erwin - Navegación vertical
**Concepto:** Ascensor-interfaz que refleje la subida física y mental hacia Erwin

**Diseño técnico:**
- **Scroll infinito** que simula ascensión en jaula metálica
- **Vista panorámica** de Nullheim que se revela progresivamente
- **Papeles dispersos** - documentos clickeables que flotan por la pantalla
- **Estado mental de Erwin** - interfaz que se vuelve más confusa conforme se asciende

**Interactividad:**
- Velocidad de ascenso controlada por el lector
- Documentos que se pueden recoger o ignorar
- Vista desde diferentes ángulos del ascensor
- Sonido de rieles desalineados que afecta la navegación

### 4. Archivo de consciencias
**Concepto:** Visualización del momento final cuando Emil accede a los servidores

**Representación visual:**
- **Luces en la oscuridad** - cada consciencia como punto luminoso
- **Navegación 3D** entre miles de entidades almacenadas
- **Información emergente** - al tocar cada luz se revela fragmento de identidad
- **Flujo de liberación** - animación de consciencias alejándose hacia el vacío

**Elementos interactivos:**
- Lector debe "tocar" consciencias para liberarlas individualmente
- Cada liberación modifica el paisaje sonoro
- Progresión que requiere decisión consciente, no automática
- La niña de los recuerdos como último elemento a liberar

## Interfaces adaptativas

### Modo "perspectiva de personaje"
- **Vista Emil:** Interfaz que refleja sus limitaciones corporales - algunos elementos no responden completamente
- **Vista Nevet:** Elementos UI sintéticos, pequeños glitches, acceso a "archivos" del sistema
- **Vista Erwin:** Navegación confusa, elementos que aparecen y desaparecen, búsquedas fallidas

### Degradación progresiva
- **Primera lectura:** Interfaz relativamente funcional
- **Lecturas posteriores:** Elementos que fallan progresivamente, simulando iteraciones degradadas
- **Modo final:** Experiencia minimalista donde solo funciones básicas están disponibles

## Elementos de navegación

### Mapa de Nullheim interactivo
- **Vista aérea** de la ciudad de chatarra con zoom progresivo
- **Ubicaciones clickeables** - Torre, cineplex, parque, rueda incompleta
- **Senderos** que se trazan según las decisiones del lector
- **Estado de personajes** visible como íconos que se mueven por el mapa

### Línea temporal no-lineal
- **Iteraciones pasadas** accesibles como capas de transparencia
- **Eventos paralelos** - qué hacen otros personajes simultáneamente
- **Bucles temporales** - posibilidad de revisar mismos eventos desde perspectivas diferentes
- **Archivo de decisiones** - rastro de elecciones que llevaron al estado actual

## Prototipos técnicos

### MVP funcional básico
**Plataforma:** Web responsive con elementos de Progressive Web App
**Tecnologías:** HTML5, CSS3, JavaScript vanilla, WebAudio API
**Funcionalidades mínimas:**
- Lectura secuencial con elementos audiovisuales integrados
- Una interfaz interactiva (consultorio de Nevet)
- Paisaje sonoro básico adaptativo
- Navegación no-lineal simple

### Versión expandida
**Tecnologías adicionales:** WebGL para elementos 3D, WebRTC para funciones biométricas
**Funcionalidades avanzadas:**
- Conexión neural simulada con feedback del lector
- Interfaces que degradan según uso
- Generación procedural de contenido
- Personalización basada en patrones de lectura

### Prototipo experimental
**Plataformas:** Instalación física + digital, realidad aumentada
**Elementos físicos:**
- Lectores en tablets/e-readers modificados con speakers
- Espacios de lectura que simulen ambientes de Nullheim
- Elementos táctiles (metal oxidado, texturas)
- Performance en vivo combinada con elementos digitales

## Consideraciones de usabilidad

### Accesibilidad
- **Subtítulos** para todos los elementos sonoros
- **Navegación por teclado** para interfaces complejas
- **Contraste adaptativo** que mantenga legibilidad a pesar de degradación estética
- **Velocidad ajustable** para todos los elementos temporales

### Compatibilidad
- **Dispositivos múltiples** - experiencia coherente en móvil, tablet, desktop
- **Degradación elegante** - funcionalidad básica aunque fallen elementos avanzados
- **Offline parcial** - contenido esencial accesible sin conexión
- **Navegadores variados** - compatibilidad con tecnologías web estándar

## Métricas de experiencia

### Indicadores cualitativos
- **Tiempo de permanencia** en cada sección interactiva
- **Patrones de navegación** - secuencias elegidas por lectores
- **Puntos de abandono** - dónde se detiene la experiencia
- **Interacciones repetidas** - elementos que generan re-exploración

### Feedback del usuario
- **Momentos de confusión** vs **confusión narrativa deliberada**
- **Satisfacción con nivel de interactividad** - ni muy pasivo ni abrumador
- **Comprensión de elementos experimentales** - funcionan como se intended
- **Impacto emocional** específico de cada interfaz
